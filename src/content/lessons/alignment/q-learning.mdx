Can an agent learn the best action without knowing how the world works?

<Step title="Q-values: how good is each action here?">

A Q-value scores a pair of state and action: the return you expect if you take that action now and act well afterwards, so the best action is simply the one with the highest Q.

<Step title="The Bellman equation">

The Bellman optimality equation says a Q-value equals the immediate reward plus the discounted value of the best action in the next state, averaged over where you might land.

{/*
IDEA: Q*(s,a) = sum_s' P(s'|s,a) [R + gamma max_a' Q*(s',a')]. Value iteration applies it as an update until it stops changing.
WIDGET: GridWorldLab mode="bellman" focus="3,1" action="up" sweeps=20. Shows one backup at the focus cell: the three successor cells with their max-Q, the probabilities, and the weighted sum assembling into the new Q.
MOTION over t: first segment: the single backup assembles term by term (arrows carry each weighted term into the sum). Second segment: whole-grid sweeps, all Q triangles tween to each sweep's values; the max change per sweep plotted below on a log axis.
TRY: watch the max-change curve fall by roughly a constant factor per sweep.
NUMBERS: the three weighted terms and their sum at the focus cell (sweep k shown); max change after 20 sweeps.
SHOW THE MATH: Bellman optimality equation for Q and V; contraction in one sentence.
*/}

</Step>

<Step title="Tabular Q-learning">

Q-learning learns the same Q-values without knowing the transition probabilities, by nudging one entry toward a sampled Bellman target after every move.

{/*
IDEA: Q(s,a) += alpha [r + gamma max_a' Q(s',a') - Q(s,a)]. TD target, TD error. Epsilon-greedy behaviour, off-policy target (max).

<Step title="Learning from experience, with exploration">

How fast Q-learning learns depends on how much it explores and how big its steps are, and its estimates converge to the true Q-values only if every action keeps being tried.

<Step title="Terminal states end the target">

When an episode ends, the last reward is the whole target because there are no future actions left to value.

<Step title="Common misconceptions">

Some common misunderstandings about these methods.

{/*
NO WIDGET. Misconceptions:
1. "Q-learning needs the transition probabilities." Actually it only needs sampled transitions.
2. "Q-learning learns the policy it is following." It learns the greedy policy's values while following epsilon-greedy (off-policy).
3. "Bigger learning rate means faster learning" in tabular Q-learning. Noisy targets make large alpha oscillate.
4. "A terminal state's Q-value belongs in the target." There is no continuation after true termination.
*/}

</Step>
