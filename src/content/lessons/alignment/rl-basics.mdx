Instead of labeled answers, the learner gets only a score for what it did.

<Step title="An agent, an environment and a score">

Reinforcement learning is about an agent that takes actions, sees what happens, and receives a number called a reward, with no labeled correct answer to copy.

<Step title="A Markov decision process">

A Markov decision process writes the environment down exactly: the states, the actions, the probability of each next state, and the reward, where the next state depends only on the current state and action.

{/*
IDEA: MDP = (S, A, P, R, gamma). The Markov property: the present state is all you need. Slippery moves make transitions probabilistic.
WIDGET: GridWorldLab mode="mdp" focus="3,1" action="up". Highlighted cell with three outcome arrows (0.8 intended, 0.1 each side) drawn with widths proportional to probability; bumping a wall means staying put.
MOTION over t: cycles through the four actions at the focus cell; arrows ease to the new outcome probabilities; 20 sampled outcomes per action drop as dots into their target cells, tally fills.
TRY: pick the action next to the wall and see the "stay" probability.
NUMBERS: the sampled tallies for the shown seed vs the exact 0.8/0.1/0.1.
SHOW THE MATH: P(s'|s,a), R(s,a,s'), the Markov property in one line.
*/}

</Step>

<Step title="Policies and returns">

A policy is the agent's rule for choosing an action in each state, and the return is the sum of the rewards it collects from now on, with later rewards shrunk by a discount factor.

{/*
IDEA: policy pi(a|s) (deterministic arrows here); return G_t = r_t+1 + gamma r_t+2 + ... ; computed backward from the end of an episode.
WIDGET: GridWorldLab mode="return" policy="textbook" gamma=0.9 seed=3. Arrows of a fixed policy in every cell; one sampled episode.
MOTION over t: first half the agent walks the episode forward; second half the returns G_t fill in backward along the path, each cell's number counting up from the reward plus gamma times the next return.
TRY: compare G at the start cell with the plain sum of rewards.
NUMBERS: G_0 for this episode and the undiscounted sum.
SHOW THE MATH: G_t = sum_k gamma^k r_(t+k+1) and the recursion G_t = r_(t+1) + gamma G_(t+1).
*/}

</Step>

<Step title="What the discount factor decides">

The discount factor sets how much the agent cares about the future, and changing it can change which path is best.

{/*
IDEA: gamma near 0 is short-sighted, near 1 is patient. With slip and a pit, the best route depends on gamma: low gamma barely values the far goal.

<Step title="Value functions">

The value of a state is the return the agent can expect from there if it keeps following its policy, averaged over all the ways the slippery moves can turn out.

{/*

WIDGET: GridWorldLab mode="value" policy="textbook" gamma=1 stepReward=-0.04. Heatmap with --viz-seq-* (diverging --viz-pos/--viz-neg if negative values appear), numbers in each cell.
MOTION over t: one sweep per marker; cell values tween to the next sweep's values; the cell currently being backed up shows its three weighted successor arrows.
TRY: watch how many sweeps it takes before the start cell's value stops changing in the second decimal.

<Step title="Exploration versus exploitation">

An agent that always repeats the best action it knows may never find a better one, so it must sometimes try actions that look worse.

<Step title="Common misconceptions">

A few ideas about reinforcement learning that sound right but are not.

{/*
NO WIDGET. Intended misconceptions:
1. "The reward tells the agent what to do." Actually it scores outcomes; the agent must discover which actions led to them (credit assignment).
2. "Maximising the immediate reward is enough." Actually the return includes the future; greedy short-term choices can be worse.
3. "Exploration is wasted effort." Actually without it estimates of untried actions never improve (greedy stuck runs).
4. "Value and reward are the same." Actually value is expected future return under a policy.
5. "Discounting is just a trick for convergence." It also encodes a real preference and changes the optimal policy.
*/}

</Step>
