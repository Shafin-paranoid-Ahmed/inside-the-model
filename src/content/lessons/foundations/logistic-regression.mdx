<Step title="A line can't answer yes or no">

Sixteen points sit on a number line $x$. Each belongs to one of two classes: class 1 (blue) or class 0 (orange). Class 1 tends to sit on the right, class 0 on the left, but the two overlap in the middle. Given a new $x$, we want an answer to "which class?" together with a confidence, such as "70% likely class 1".

[Linear regression](/learn/foundations/linear-regression/) gives us a score $z = wx + b$, but a score can be $-3$ or $12$, and neither is a probability. **Logistic regression** fixes this by passing the score through a squashing function, the **sigmoid**, which turns any number into something between 0 and 1.

The left panel shows the sigmoid curve in teal. The right panel is a loss map like the ones in the previous lessons: every choice of $(w, b)$ is one curve. Watch the timeline. The model starts as a poor guess and trains until the curve sits where the classes change.

<Step title="The sigmoid squashes any score into (0, 1)">

The sigmoid is

$$\sigma(z) = \frac{1}{1 + e^{-z}}.$$

For a very negative $z$, $e^{-z}$ is huge and $\sigma(z)$ is close to 0. For $z = 0$, $\sigma(0) = 1/2$. For a very positive $z$, $e^{-z}$ is tiny and $\sigma(z)$ is close to 1. The curve is smooth and always increasing, so a larger score always means a higher probability.

Here $\sigma$ ("sigma") is the name of the function, and $e\approx2.71828$ is a mathematical constant. The expression $e^{-z}$ means raise $e$ to the power $-z$; it does **not** mean multiply $e$ by $-z$. You can calculate it with the $e^x$ or `exp` key on a calculator. The denominator is always greater than 1, so dividing 1 by it produces a value between 0 and 1.

Our model has two stages: **calculate a linear score**, then **convert that score into a probability**:

$$z=wx+b,\qquad p=P(y=1\mid x)=\sigma(z)=\frac{1}{1+e^{-z}}.$$

Read $P(y=1\mid x)$ as "the model's probability of class 1, given input $x$." The probability of class 0 is $1-p$.

Let's calculate the figure's starting point, $x=-4$, without skipping any operations. The fitted parameters are approximately $w=1.262401$ and $b=0.440404$:

1. **Multiply the input by the weight:** $wx\approx1.262401\times(-4)=-5.049604$.
2. **Add the intercept:** $z\approx-5.049604+0.440404=-4.609200$.
3. **Negate the score:** $-z\approx4.609200$. The negative score becomes a positive exponent.
4. **Calculate the exponential:** $e^{4.609200}\approx100.4038$.
5. **Add one:** $1+100.4038=101.4038$.
6. **Divide:** $p\approx1/101.4038\approx0.009862$, or about **0.986% probability of class 1**.

That is where the displayed probability of about **0.01** comes from. It is a fraction on a 0-to-1 scale; multiply by 100 to express it as a percentage. The negative score makes the denominator large, so the probability is small.

The live calculation uses the full parameter precision, giving $z\approx-4.609201$ and $e^{-z}\approx100.403910$. The small difference from the hand calculation is rounding. In particular, the shorter display $w=1.26$, $b=0.44$ gives $z=-4.60$ if you calculate from those rounded numbers; it cannot give exactly $-4.61$.

Now move **input x** to 0. Multiplying by zero removes the weight term, leaving $z=b\approx0.440404$. Then $e^{-z}\approx0.643776$, so $p\approx1/1.643776\approx0.608355$: about **60.836%**, not 44%. At $x=4$, the same sequence gives $z\approx5.490009$ and $p\approx0.995889$, or **99.589%**. Follow the dotted guides and the arithmetic below the curve as you change the input.

<Step title="w tilts the curve, b slides it">

To turn a probability into a class label, we need a rule. Here we predict class 1 above probability 0.5 and class 0 below it. At the threshold, the score is zero because $\sigma(0)=1/(1+e^0)=1/(1+1)=0.5$.

The **offset** $b$ slides the curve left or right when $w$ is held fixed. Solve $wx+b=0$ by subtracting $b$ and dividing by $w$: $x=-b/w$ (when $w\ne0$). This is the **decision boundary**, the dashed vertical line. With the fitted values, $x\approx-0.440404/1.262401\approx-0.349$. Since $w$ is positive, points to its right are predicted class 1. A negative $w$ reverses the direction.

The magnitude of $w$ sets how quickly the probability changes: small $|w|$ gives a gradual ramp; large $|w|$ gives a sharp transition. Changing $w$ with a nonzero $b$ also moves the boundary, since $-b/w$ changes.

The timeline turns one knob at a time. First only $b$ moves: the curve slides left and right without changing shape, and the dashed boundary slides with it. Then only $w$ moves: the curve flattens and sharpens. On the map, the dot travels straight up and down, then straight left and right. Afterwards, drag the sliders or click anywhere on the contour map to try your own settings.

The ring on the curve above each point is that point's predicted $P(y = 1)$. The pink stem joins it to the point's true label (1 at the top, 0 at the bottom). A long stem means the model is confidently wrong there, and it is the raw material for the loss.

<Step title="Why not squared error? Log-loss">

Until now we have only calculated probabilities. Training also needs a loss. In Day 1, MSE measured errors in predicted numbers. We could apply squared error to probabilities too, but logistic regression usually uses **log-loss**, also called **binary cross-entropy**. It gives a large penalty when the model assigns a very small probability to the class that actually occurred.

For one point with true label $y$ and predicted class-1 probability $p$, the loss is

$$\ell(p, y) = -\big[\,y \ln p + (1 - y)\ln(1 - p)\,\big].$$

Here $\ln$ is the natural logarithm, the inverse of the exponential. If $y=1$, substitution gives $-[1\ln p+0\ln(1-p)]=-\ln p$. If $y=0$, it gives $-[0\ln p+1\ln(1-p)]=-\ln(1-p)$. In either case, take minus the logarithm of the probability assigned to the true class.

For a class 1 point, $p=0.9$ gives $-\ln(0.9)\approx0.105$; $p=0.1$ gives $-\ln(0.1)\approx2.303$; $p=0.01$ gives $-\ln(0.01)\approx4.605$. Confident and wrong costs much more than confident and right. The figure averages this loss across all sixteen points. A model that always predicts $0.5$ has loss $-\ln(0.5)\approx0.693$; a lower average beats that constant-probability baseline on these data.

Watch the curve steepen while $(w, b)$ moves along the dashed line on the map, scaled from 0.1 to 3 times the best fit (the boundary stays put). Too flat, the loss is 0.634 because nothing is decided. At the best fit it is 0.452. Beyond that the curve becomes overconfident on the overlapping points, and at three times the fit the loss climbs back to 0.651. Only the middle setting is the right amount of confidence for this data.

<details>
<summary>Show the math</summary>

Suppose each label is a coin flip with $P(y = 1) = p_i$. The likelihood of independent labels is $\prod_i p_i^{y_i}(1 - p_i)^{1 - y_i}$. Taking $-\frac{1}{n}\ln$ of it gives the mean log-loss, so minimizing log-loss is maximum likelihood estimation. With squared error after the sigmoid, the score derivative includes a factor $p(1-p)$ that becomes small near 0 or 1, even for confident mistakes. With log-loss the score derivative simplifies to $p-y$. The mean logistic log-loss is convex in $(w,b)$, though progress can still be slow in flat directions.

</details>

</Step>

<Step title="Training: the gradient is prediction minus truth">

Log-loss has a remarkably tidy gradient. Using $\sigma'(z) = \sigma(z)(1 - \sigma(z))$, the sigmoid's slope cancels against the log, leaving

$$\frac{\partial L}{\partial w} = \frac{1}{n}\sum_i (p_i - y_i)\,x_i, \qquad \frac{\partial L}{\partial b} = \frac{1}{n}\sum_i (p_i - y_i).$$

Each point pushes with a force equal to its error $p_i - y_i$, the same stem you see in the figure. A class 1 point with a low $p$ pulls the curve up towards it; a class 0 point with a high $p$ pushes it down.

The **training procedure is still gradient descent**: calculate the current loss gradients, then subtract the learning rate times each one. The prediction now includes a sigmoid and the loss is now log-loss, so the gradient formulas change. The update rule does not.

Start at $w=0.1$, $b=-2.2$, where log-loss is 1.173. The gradient is approximately $(-0.304193,-0.403397)$. With learning rate $0.5$:

$$w_{\mathrm{new}}\approx0.1-0.5(-0.304193)\approx0.252096,$$
$$b_{\mathrm{new}}\approx-2.2-0.5(-0.403397)\approx-1.998301.$$

Recompute the probabilities and log-loss at these parameters: the loss falls to **1.050**. After 10 updates it is **0.558** and after 40 it is **0.453**, about **0.0011** above the minimum **0.4521**. With a suitable learning rate, descent approaches this dataset's finite optimum; forty updates do not reach it exactly.

This figure shows the gradient itself. The magenta arrow on the map is the next step, $-0.5\,\nabla L$, drawn from the dot. The readout writes out both partial derivatives and where the step lands. Watch the arrow shrink as the dot nears the diamond: near the minimum the errors $p_i - y_i$ mostly cancel, so the gradient fades. Then click anywhere on the map to place your own starting guess and press Play. Training runs from your guess and heads for the same diamond, because there is only one bottom. From a far corner, such as large $w$ and large $b$, 40 steps are not enough: the valley floor there is nearly flat, so the arrow is tiny and progress is slow. That is a real weakness of plain gradient descent, and Day 6's optimizers are built to fix it.

<details>
<summary>Show the code</summary>

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def train(x, y, lr=0.5, steps=40):
    w, b = 0.1, -2.2
    for _ in range(steps):
        p = sigmoid(w * x + b)
        w -= lr * np.mean((p - y) * x)
        b -= lr * np.mean(p - y)
    return w, b
```

</details>

<Step title="Common misconceptions">

- **You might think** logistic regression is a regression that predicts numbers. **Actually** it is a classifier: the "regression" is the linear score inside, and the output is a probability.
- **You might think** a probability of 0.9 means the model is 90% accurate. **Actually** it says that among inputs like this one, about 90% should be class 1. Whether that holds is a separate question (calibration).
- **You might think** the fit should get every point right. **Actually** the classes overlap here, so the best curve still misclassifies some points (11 of 16 are correct at the optimum). Forcing them all right only makes the curve overconfident.
- **You might think** the sigmoid makes the model non-linear in the input. **Actually** the boundary $wx + b = 0$ is still a straight cut; the sigmoid only shapes how confidence grows.

</Step>

</details>

<details>
<summary>What does scaling both $w$ and $b$ up by the same factor do to the curve?</summary>

The boundary $-b/w$ stays put and the curve gets steeper around it, so the model becomes more confident on both sides.

</details>

<details>
<summary>Why is the gradient for a point just $(p - y)\,x$?</summary>

The sigmoid's derivative $p(1 - p)$ cancels with the $1/p$ and $1/(1 - p)$ from differentiating the logarithm, leaving the error $p - y$ times the input.

</details>
